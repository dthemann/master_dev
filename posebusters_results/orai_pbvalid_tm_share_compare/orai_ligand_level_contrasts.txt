############################################################################################

generated 2026-08-16 14:48:15 by Scripts/Analysis/orai_ligand_level_contrasts.py

WHY: the shipped Orai cross-panel sidecars treat the (MD frame x ligand) pair as the
independent unit. The four Orai1 frames are snapshots of the SAME receptor, so a
ligand's four units are repeated measures of ONE receptor-ligand system. With three
experimental ligands the effective n is 3, not 12 -- the (frame x ligand) tests are
anti-conservative for the ligand-generalisation question. Every family below is
recomputed at BOTH units with the same machinery (two-sided Mann-Whitney U,
Cliff's delta with a percentile-bootstrap 95% CI, then Holm or BH-FDR within the
stated family). Nothing was re-docked; all inputs are committed CSVs.

UNIT DEFINITIONS
  frame x ligand : one row per (MD frame, ligand) -- reproduces the shipped numbers.
  ligand         : each ligand collapsed to the MEDIAN of its per-frame values
                   FIRST, so one ligand contributes exactly one observation.

ORIENTATION: every Cliff's delta is Benchmark vs Experimental, so delta > 0 means the
Benchmark (control) values are higher. NOTE the shipped
orai_cluster_quality_compare_stats.txt prints delta with Experimental as the first
group, i.e. with the OPPOSITE sign; the p-values are unaffected (U is symmetric).

SCOPE / ligand exclusions
  ligand-name exclusion patterns applied (from the compare script): ['gsk7975a-deprot']
  -> the 'deprotonated' GSK-7975A build is excluded everywhere, so the Experimental
     set is 3 ligands (2-APB-NH2, Synta-66, GSK-7975A protonated) x 4 MD frames.

  HONEST CHARACTERISATION FOR THE PROSE:
    With three experimental ligands the Orai Experimental-vs-Control comparison is
    DESCRIPTIVE, not inferential. Report medians, per-ligand points and Cliff's delta as
    effect sizes, and state the direction of the difference; do NOT claim statistical
    significance for any Experimental-vs-Control contrast. Where an adjusted p is quoted
    at all it must be labelled as the (frame x ligand) unit, flagged as pseudoreplicated
    (frames are snapshots of one receptor-ligand system), and paired with the ligand-unit
    value from this sidecar. The interaction-type contrasts currently reported as
    surviving Benjamini-Hochberg are in the same position: none survives at the ligand
    unit (section D2).

============================================================================================
CAVEATS
============================================================================================
  * The ligand unit fixes the FRAME pseudoreplication only. Three experimental
    ligands remain three ligands. With n_exp = 3 (or 2) the entire test statistic is
    the rank position of those few values inside a ~300-ligand reference
    distribution: a small p means 'all 2-3 experimental ligands sit in the
    Benchmark tail', which one atypical ligand can create or destroy. Such a p
    is a statement about THOSE ligands, not evidence that the next experimental
    ligand would behave the same way.
  * The two arms are UNPAIRED (different ligand sets), so no paired test applies.
  * Cliff's delta bootstrap CIs at n_exp = 3 span most of [-1, 1]; they are printed
    in the CSV for completeness, not as a precision claim.
  * Frames of one ligand are correlated but NOT identical (different receptor
    snapshots), so the median-over-frames collapse is a conservative summary, not
    a claim that the frames carry no information.
